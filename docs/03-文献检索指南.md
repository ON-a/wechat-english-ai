## 一、检索准备

### 1.1 访问知网

- 网址：https://www.cnki.net
- 推荐通过**学校图书馆入口**登录（学校已购买知网权限，可免费下载全文）
- 若在校外，可使用学校 VPN 或"校园 CARSI 联盟"登录

### 1.2 外文数据库

- **Google Scholar**：https://scholar.google.com
- **IEEE Xplore**：https://ieeexplore.ieee.org
- **ACM Digital Library**：https://dl.acm.org
- **ScienceDirect**：https://www.sciencedirect.com
- 同样推荐通过学校图书馆入口访问

### 1.3 检索思路

本课题涉及多个交叉领域，建议按以下**四大主题**分别检索，再汇总去重：

1. **AI / 大语言模型 + 英语口语教学**
2. **语音识别（ASR）/ 语音合成（TTS）+ 语言学习**
3. **微信小程序 + 教育应用开发**
4. **口语评估 / 自动评分 / 对话系统**

## 四、文献管理建议

1. **使用文献管理软件**：推荐 **Zotero**（免费）或 **EndNote**，方便插入引用和生成参考文献列表。
2. **命名规则**：下载 PDF 后统一命名为"年份-作者-题名"，如 `2024-张进宝-生成式人工智能赋能英语口语教学.pdf`。
3. **阅读笔记**：每篇文献记录"研究问题、方法、结论、对我课题的启发"四点。
4. **引用格式**：毕业论文通常采用 **GB/T 7714-2015** 格式，注意中文和外文文献的格式区别。

## 五、快速上手步骤

1. 登录知网 → 高级检索；
2. 依次使用"中文文献检索"中的 11 个检索式检索；
3. 按时间（2020 后）+ 核心期刊筛选；
4. 从每个主题方向中挑选下载量/被引高的文献，凑齐 20 篇；
5. 用 Google Scholar 按外文检索式找 5 篇；
6. 导入 Zotero，开始阅读并做笔记。

> **小技巧**：如果某方向文献过多，可增加限定词（如加"系统设计"、"应用研究"）缩小范围；如果过少，可去掉"核心期刊"勾选或放宽时间到 2018 年。
