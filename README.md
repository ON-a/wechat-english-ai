# 基于微信小程序的英语口语 AI 陪练系统

> 毕业设计项目 | 微信小程序 + 大语言模型 + 语音技术

## 项目简介

一个基于微信小程序的英语口语 AI 陪练系统，支持多场景选择、多模型切换，为用户提供沉浸式、个性化的口语对话练习体验。

## 核心特性

- 🎯 **多场景对话**：日常生活、校园、职场、旅行、面试等典型场景
- 🤖 **多模型可选**：支持通义千问、DeepSeek、文心一言等大模型切换
- 🎙️ **语音交互**：ASR 语音识别 + TTS 语音合成，全链路语音对话
- 📝 **实时反馈**：语法纠正、发音评分、词汇建议
- 📊 **学习记录**：历史对话回看 + 学习数据统计

## 技术栈

- **前端**：微信原生小程序
- **后端**：Node.js (NestJS) / Python (FastAPI)
- **大模型**：通义千问 / DeepSeek / 文心一言
- **语音**：微信同声传译 / 阿里云 ASR & TTS
- **数据库**：MySQL + Redis
